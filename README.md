# Vibe District - Premium Headwear E-commerce

Vibe District is a professional, high-end e-commerce platform dedicated to premium streetwear caps and durags. Born in the heart of Lagos, Nigeria, the brand represents a fusion of quality craftsmanship and authentic street culture.

## Features

- **Professional Shopping Experience**: Browse through a curated collection of snapbacks, durags, and custom caps.
- **Advanced Shopping Cart**: Seamlessly add, remove, and adjust quantities of items with real-time total calculations.
- **Real-time Order Tracking**: Track your order's progress with a visual pictorial representation of the delivery timeline.
- **WhatsApp Integration**: Direct ordering and support via WhatsApp for a personalized customer experience.
- **Mobile Optimized**: Beautiful and responsive UI designed for all devices.
- **Secure Checkout**: Robust checkout flow with multi-step validation.

## Tech Stack

- **Frontend**: React 18, Vite, TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion (motion/react)
- **Icons**: Lucide React
- **Routing**: React Router 7
- **Notifications**: Sonner

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   pnpm install
   ```
3. Start the development server:
   ```bash
   pnpm dev
   ```
